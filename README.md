# مستشار الطاقة 🔋
## Energy Advisor App

تطبيق Streamlit بسيط وعملي لتقديم نصائح صحية بناءً على مستوى الطاقة

### المميزات:
- 📊 سلider تفاعلي لقياس مستوى الطاقة من 1 إلى 10
- 💡 نصائح صحية مخصصة حسب مستوى الطاقة
- 🌍 واجهة باللغة العربية

### التشغيل المحلي:
```bash
pip install -r requirements.txt
streamlit run app.py
```

### النشر على Streamlit Cloud:
1. اذهب إلى https://share.streamlit.io/
2. اختر هذا المشروع من GitHub
3. اضغط Deploy
